2 · The pipeline, and the trap at each stage

1
DATA SOURCE
market / onchain / social / disclosure
market.py, onchain.py, social.py, disclosure.py
A fetch can fail, be rate-limited, or return a different subset than the last fetch. Every fetch records its provenance: URL, HTTP status, and what was measured.
2
FEATURE
indicators, the volatility risk premium, funding/OI
leading.py, cryptoderivs.py, regime.py
A leading feature must be timestamped and aligned with a one-bar publication lag, or it is not leading - it is look-ahead. A missing value is None, never zero.
3
SIGNAL
features -> per-symbol positions
backtest.py, ensemble.py, trend.py
The signal says WHICH WAY. The portfolio block does the sizing. A signal that ignores invert_signal produces a negative control that cannot fail.
4
PORTFOLIO & RISK
weights, caps, vol target, kill switch
portfolio.py, riskguard.py, costs.py, friction.py
The caps are applied LAST. The kill switch downgrades an ENTER to an AVOID - but there is still no order-placement path for it to gate.
5
SIMULATION
the engine's 8-stage gauntlet
btengine.py / btvalidate.py (the shared skill)
Walk-forward with purge and embargo, cost stress, gross-vs-net, parameter sweep, Monte Carlo, subperiod, capacity, replication, causality audit.
6
VERDICT
SUPPORTED / FRAGILE / REFUTED / INCONCLUSIVE / ERROR
backtest.py, pbo.py, edge.py
A crash is an ERROR, not an INCONCLUSIVE. The pooled OOS Sharpe is the result; the in-sample Sharpe is reported beside it and never substituted for it.
7
REPORT
markdown, JSON, inline-SVG dashboards
paperreport.py, backtestviz.py, report.py
The report separates a finding from a crash, scopes the discrimination claim to the controls that executed, and says which stages never ran.
